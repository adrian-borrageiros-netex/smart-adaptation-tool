Cómo se usa

Una vez: arrastra este botón a la barra de marcadores del navegador. Si tenías el anterior, «Enviar a Sarela», sustitúyelo por este.

Sarela

Para traer una unidad: en learningCloud, abre la carpeta que contiene la unidad y sus actividades y pulsa el marcador. En la ventana de Sarela que se abre, «Traer esta carpeta» y después «Subir a Sarela».

Para enviar unidades adaptadas: abre cualquier página de learningCloud y pulsa el marcador. En la ventana de Sarela, elige las unidades y «Enviar las elegidas».

Todo se hace con tu sesión de learningCloud, que no sale de learningCloud. Esta página solo atiende a {{ origenes | join(', ') }}. Si el navegador bloquea la ventana, permite las ventanas emergentes de learningCloud.
